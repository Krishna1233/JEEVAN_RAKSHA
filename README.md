🛡️ JEEVANRAKSHA
### Building Safer & Smarter Cities

**A Citizen-Focused Civic Issue Reporting and Monitoring Platform**

JEEVANRAKSHA is an independent civic-tech prototype developed for the **CityFix Buildathon**. It aims to make urban civic issue reporting more accessible, organized, and transparent.

## 🌍 Problem Statement

Citizens face difficulties reporting and tracking common civic issues such as:
- Road damage and potholes
- Garbage management
- Flooding and waterlogging
- Streetlight failures
- Water supply problems
- Drainage issues
- Public safety concerns

JEEVANRAKSHA provides a centralized prototype for reporting and monitoring these issues.

## 💡 Our Solution

The platform allows citizens to submit civic issue reports, receive unique tracking credentials, and monitor report status.

## 🚀 Key Features

1. **Smart Issue Reporting** – Submit different types of civic issues.
2. **Secure Report Tracking** – Track reports using a Ticket ID and private access code.
3. **Photo Evidence Preview** – Upload and preview problem photographs.
4. **Priority Assessment** – Keyword-based High, Medium, and Low priority suggestions.
5. **City Intelligence Dashboard** – View aggregated reports and issue statistics.
6. **Admin Panel** – Review reports and update their status.
7. **Emergency Help Center** – Access emergency assistance information.
8. **Government Help Finder** – Find relevant government information and official portals.
9. **Privacy-Focused Design** – Protect report access using hashed access codes.

## ⚙️ Technology Stack

- Python
- Streamlit
- Supabase
- PostgreSQL
- GitHub
- Streamlit Community Cloud

## 🔄 How It Works

1. Citizen selects a civic issue category.
2. Citizen submits the issue details.
3. The system generates a unique Ticket ID and private access code.
4. Report information is stored in the database.
5. Citizen uses the credentials to track report status.
6. Dashboard displays aggregated report statistics.

## 🔐 Privacy & Responsibility

- Private access codes are stored as SHA-256 hashes.
- Public dashboard displays aggregated information.
- Uploaded photographs are currently previewed during the reporting session and are not permanently stored.
- Optional area details, PIN code and contact preference are not currently saved.
- The platform is not affiliated with any government authority.
- Reports do not automatically reach government departments.

## ⚠️ Current Limitations

- Priority assessment is keyword-based, not an AI-based emergency verification system.
- Government Help Finder provides search-based discovery, not verified automated case routing.
- Resource Matching is a planned enhancement and is not currently active.
- The prototype does not guarantee government action or resolution of reported issues.
